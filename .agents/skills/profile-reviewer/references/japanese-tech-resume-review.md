# Japanese Tech Resume Review Guide

Use this reference for deeper review of Japanese resumes for developers, engineers, and technical professionals.

## Recruiter vs Direct Company

- Recruiter-ready documents should be easy to map to roles: desired roles, desired areas, seniority, work style, and language ability.
- Direct-company documents can be slightly less explicit about preferences, but constraints such as relocation, visa support, shift work, or location still matter when applicable.
- A single general-purpose version is usually acceptable if it is factual, compact, and not overly tailored to one recruiter.

## Common Strength Signals

- Relevant technical experience with clear progression.
- Recent work aligned with the target role, such as software development, infrastructure, embedded systems, QA, data, mechanical/electrical engineering, or technical support.
- Clear scale where applicable: users, systems, products, projects, budget, production volume, teams, sites, environments, or customers.
- Achievements with measurable impact or clear operational/business value.
- Certifications, licenses, language ability, and communication scope stated honestly.

## Common Risks

- Overstating language ability beyond the contexts where the user is comfortable.
- Making 職務経歴書 too long by listing every tool, technology, method, or task for older roles.
- Mixing 学歴 and 職歴 chronologically in 履歴書 when a traditional format expects separated headings.
- Using `資格`, `認定`, or `合格` for courses that were only attended.
- Over-tailoring a reusable resume to one recruiter/company.

## Suggested Phrasing

- `日本への転職・移住を積極的に希望`
- `ビザサポート希望。実務経験および保有資格に基づき、在留資格要件を満たす見込みです。`
- `日本語での社内コミュニケーションに対応可能です。英語での技術調整にも対応可能です。`
- `設計・改善・実装を担うハンズオンの技術職を希望します。`
- `専門性を活かし、品質向上・業務改善・関係者との連携に貢献したいと考えています。`

## Send-Readiness Checklist

- PDF opens and has no missing glyphs.
- No text is clipped.
- 職務経歴書 is 2-3 pages and scan-friendly.
- 履歴書 has photo, date, contact details, and separated 学歴/職歴 when possible.
- Sensitive personal data is intentional.
- File names are clear enough for a recruiter.
